# 过程记录

## 2026-10-20

要求 agent 先生成一份计划文档（`doc/实现计划.md`），再按该计划分步搭建。架构说明的初版据此写成，代码尚未开始。

## 2026-10-20 第 1 步

`executeLine` 按第 7.2 节固定顺序：空行和注释不产生输出；未闭合引号在进入命令之前失败；未知命令先于「没有文档」；「没有文档」先于 usage。`help`、`init`、`read` 不需要文档。

依赖表不允许 `cli` 引用 `app`，组件图里的 `Repl → EditorSession` 因此落成 `Repl` 只调用 `executeLine`，由 `Program` 把会话装进去。

管道里没有终端回车。非交互时在读到一行之后先补一个换行，命令输出才另起一行；交互终端仍由回车换行。

除 `help` 外，命令只做了登记。参数合法的 `init` 和 `read` 还没有文档可改，目前会抛出未捕获异常。

## 2026-10-20 第 2 步

图形类各自实现几何、树上的 detail 和 SVG 标签。类型名只在 `ShapeFactory` 登记。命令还没有接到这些类上。

组的 `move` / `scale` 递归改子孙的数值，组自己不记坐标。`captureFields` 只含本节点的几何和外观；父子关系另由结构快照保存对象引用。因此撤销一组的移动时，要快照整棵子树的字段，不能只快照组本身。

列对齐只统计 detail 非空的行，列号是这些行里前缀长度加标签长度的最大值再加 2。手写小树、第 9 节第一棵树和 `other.svg` 的树都按这个结果逐字比较。

流程图期望树里的 `line#arrow1` 原先没有 `stroke=black`。创建参数 `black` 是 stroke，detail 表又要求写上已设置的外观，所以期望树补了这一段，列号仍是 32。

元素上缺了几何属性就失败，消息是 `invalid svg: missing attribute: <name>`。`px` 留给第 5 步的读取器，模型只解析纯数字。
